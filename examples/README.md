# Examples

Patch rule samples for **ncproxy** (`examples/ncproxy/`).

| File | Purpose |
|------|---------|
| `patch01.json` / `patch01.yaml` | Strip capabilities during `<hello>` |
| `patch02.json` / `patch02.yaml` | Replace `rpc-error` with `rpc-reply` ok |
| `patch03.json` / `patch03.yaml` | Auto-respond to `copy-config` |
| `patch-response-file.json` | Auto-respond using `response-file` |

See [docs/ncproxy.md](../docs/ncproxy.md).
